# Управление IT-проектам

## Факторы оценки успеха it-проекта

Жизненный цикл

Инициация -> Планирование -> Выполнение -> Контроль -> Завершение

## Основные метрики:

### Технические метрики
1. Uptime -- процент времени, в течение которого система (приложение) доступно пользователям без перебоев
2. Уровень сбоев -- процент сессий взаимодействия межлу пользователем и приложением, которые завершились сбоем
3. Время отклика системы -- время, необходимое для обработки запроса
4. Задержка -- любая задержка во время выполнения запросов

Качество кода -- совокупность значений разных характеристик кода
- число багов
- тестовое покрытие
- оценка технического долга

### Продуктовые метрики
1. Удовлетворенность пользователей -- оценка взаимодействия клиентов с продуктом через опросы, отзывы и рейтинги
2. Уровень удержания пользователей -- процент пользователей, продолжающих использователей через какой-то отрезок времени
3. Конверсия -- процент пользователей, совершивших целевое действие в веб или мобильном приложении: регистрация, покупка, подписка
4. Активные пользователи (DAU/MAU) -- количество уникальных активных пользователей за день (D) или за месяц (M)
5. Время выхода на рынок -- время, которое потребовалось для разработки и вывода продукта (функции) на рынок

### Управленческие метрики
1. Скорость разработки -- количество задач/пользовательских историй, которые команда завершает за 1 спринт (цикл разработки)
2. Отклонение от бюджета -- разница между запланированным и фактическим бюджетом проекта
3. Время выполнения задачи -- врем от появления задачи в бэклоге до ее завершения
4. Время цикла -- время, необходимое для выполнения задачи
5. Удовлетворенность команды -- показатель, насколько команда довольно проектом, процессами и условиями работы. Измеряется через обратную связь и опросы
6. Возврат инвестиций ROI -- оценка доходности проекта относительно вложенных в него ресурсов позволяет измерить финансовую эффективность продукта
